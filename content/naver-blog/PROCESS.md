# Ain 관세 인사이트 카드뉴스 제작·게시 프로세스

모든 글은 아래 순서를 지킨다. 4단계(법령 검증)를 통과하지 않은 글은 렌더링·게시하지 않는다.

1. **주제 선정·1차 조사** — 판례·심판례·법령은 korean-law MCP(법제처 DB) 원문으로 확인한다. 사건번호·선고/결정일·인용/기각을 원문 기준으로 기록 (`topics/0N-*.md`).
2. **원고 작성** — `posts/0N/post.json`(카드), `posts/0N/body.md`(본문). 스키마는 `design/post-schema.md`.
   본문은 `references/writing-style.md`를 따른다: 기업 수출입 관리 담당자 대상(관세사가 아닌 실무자 눈높이), 가볍고 짧게(본문 600~900자), 핵심만 전하고 상세 내용은 아인합동관세사무소 문의로 유도.
3. **작성자 표기** — 카드·본문 문단에는 이름을 쓰지 않는다. 템플릿이 마지막(출처) 카드에만 자동으로 넣는다: 정석현 대표관세사 · 010-7906-5432 · jsh@aincustoms.com · 02-518-5435 · aincustoms.com. 본문은 맨 끝 `상담 안내`에만 같은 정보를 쓴다.
4. **법령 검증 (필수 게이트)** — 카드·본문에 인용한 모든 법률·시행령·시행규칙 조문을 korean-law MCP로 **현행** 법제처 원문과 대조한다.
   - 조·항·호 번호, 인용 문구, 비율·기간(10%, 60%, 2개월, 1년 등), 시행일을 확인한다.
   - 결정문이 구법을 인용하면 "구 ○○법 제○조"로 표시하고 현행 조문 번호를 병기한다.
   - 결과를 `law-check.md`에 글별 표로 남기고, `post.json`에 `"lawCheck": { "checkedOn": "YYYY-MM-DD", "basis": "korean-law MCP 현행 법제처", "report": "law-check.md" }`를 기록한다.
   - `design/render-posts.mjs`는 `lawCheck.checkedOn`이 없거나 30일보다 오래된 글을 렌더링하지 않는다.
5. **렌더링** — `PLAYWRIGHT_DIR=<playwright 설치 폴더> node design/render-posts.mjs 0N`. overflow 검사가 모두 `ok`인지, PNG를 직접 열어 잘림·겹침이 없는지 확인한다.
6. **독립 검토** — 별도 검토자가 법적 정확성·카드/본문 일치·맞춤법·디자인을 검토하고 `review.md`에 PUBLISH/HOLD를 기록한다.
6-1. **태그(네이버 검색 노출)** — 글마다 12~15개. 공통 핵심 5개 `관세 관세사 수입통관 아인합동관세사무소 정석현관세사` + 글 주제 태그 8~10개.
   외환·외국환·핸드캐리·품목분류 같은 키워드는 **그 글의 내용과 맞을 때만** 넣는다. 무관한 태그를 모든 글에 반복하면 네이버가 스팸 신호로 보고 블로그 노출이 떨어진다.
   제목에는 사람들이 실제 검색하는 말(예: 핸드캐리 수입, 품목분류 사전심사)을 앞쪽에 둔다.
7. **게시** — Aside(`aside exec`)로 스마트에디터에 게시. 이미지는 개별 삽입, 해시태그는 태그란, 링크 미리보기 제거. 이미 게시된 글은 새 글을 만들지 않고 **수정**한다. 첫 이미지(card-01)를 반드시 **대표 이미지**로 지정한다(안 하면 RSS·홈페이지·네이버 검색에 썸네일이 빠진다).
8. **게시 확인** — 비로그인 상태로 모바일 주소(m.blog.naver.com)를 열어 제목·카테고리·이미지 8장을 확인하고 `posts/index.json`에 URL을 기록한다.
9. **자체 도메인 페이지 갱신 (SEO/GEO)** — 네이버 게시 확인 후 `node scripts/build-news-pages.cjs`를 실행해 `news/{id}.html`·`sitemap.xml`·`feed.xml`·`llms.txt`·`lib/news-local-posts.json`을 다시 만들고 함께 커밋·배포한다. 네이버 블로그는 AI 크롤러(GPTBot·ClaudeBot·PerplexityBot 등)를 막고 있어, AI 검색 인용은 aincustoms.com의 이 페이지로만 가능하다. 네이버 RSS에 올라온 글만 페이지가 생긴다.
