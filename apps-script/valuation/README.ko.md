## 장애/롤백

- 우선 이용/쓰기를 멈추고 현재 상태를 다시 보관합니다.
- v2 긴급 차단: 세션 키 속성을 삭제하면 인증/쓰기가 설정 오류로 차단됩니다. 데이터는 삭제하지 않습니다.
  재초기화로 새 키가 생기면 기존 토큰이 무효가 됩니다. 별도 구버전 배포는 이 조치로 차단되지 않으므로 함께 확인합니다.
- 프런트만 되돌리면 v2 API와 맞지 않습니다. 프런트/서버를 검증된 같은 계약 버전으로 전환해야 합니다.
- 구버전에는 미인증 조회/변경 문제가 있으므로 단순 공개 롤백으로 보안 문제를 다시 열지 않습니다.
  접근 제한 상태에서 원본 비교·수정 또는 안전한 v2 수정본 재배포를 우선합니다.
- 새 입력이 발생했다면 과거 DB 사본을 통째로 덮어쓰지 않습니다.
  변경분을 대조해 승인 후 필요한 행만 복원합니다. 코드만 고장난 경우 DB 복원은 하지 않습니다.
- 타임아웃은 실패를 의미하지 않을 수 있습니다. 반복 추가/삭제 대신 새로고침으로 완료 여부부터 확인합니다.

- 과거 버전의 비밀번호 로그는 새 코드로 소급 제거되지 않습니다. 실제 유출 여부는 확인하지 않았습니다.
  기존 로그 접근 범위 점검과 필요한 비밀번호 교체는 별도 승인받습니다.

  자동 trim이나 일괄 초기화는 하지 않습니다.
- 로그아웃은 브라우저의 세션/표/입력을 제거합니다. 이미 복사된 토큰까지 개별 서버 폐기하는 저장소는 없으며 최대 8시간 유효합니다.
  비밀번호/화주 변경 또는 세션 키 교체 시 해당 토큰은 다음 요청에서 무효가 됩니다.
- 반복 로그인 방어/계정 잠금, 서버 감사 이력, 정기 DB 백업 예약은 이번 패치에서 새로 구성하지 않았습니다.
  현재 DB 백업 도구는 관리자 수동 전체 사본 방식입니다.
- 직접 편집/다른 Apps Script와 동시 쓰기, Google 실행시간·할당량, 실제 서식/권한은 Node mock 시험만으로 보장할 수 없습니다.
