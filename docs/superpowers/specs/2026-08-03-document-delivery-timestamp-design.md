# 서류전달 O 전환시각 설계

## 목표

관리자 및 삼현 화면의 `서류전달` 열에서 `삼현`, `창고` 상태를 X에서 O로 변경한 정확한 날짜와 시간을 보존하고, O 상태에 마우스를 올리면 한국시간으로 확인할 수 있게 한다.

## 데이터 모델

- 기존 `docs_delivered_samhyeon`, `docs_delivered_warehouse` O/X 값은 유지한다.
- 기존 날짜 컬럼도 이전 데이터와 호환을 위해 유지한다.
- `cargo_card_user_inputs`에 다음 `timestamptz` 컬럼을 추가한다.
  - `docs_delivered_samhyeon_at`
  - `docs_delivered_warehouse_at`
- 기존 O 데이터에는 임의 시각을 소급 생성하지 않는다. 새 시각이 없으면 기존 날짜를 호버에 표시한다.

## 저장 규칙

- X에서 O로 바뀌면 서버가 현재 시각을 `timestamptz`로 저장한다.
- O 상태를 다시 O로 저장할 때는 최초 O 전환시각을 유지한다.
- O에서 X로 바뀌면 해당 날짜와 시각을 모두 비운다.
- 삼현과 창고 상태 및 시각은 서로 독립적으로 저장한다.
- 동일 화주/B/L의 연결 계정에서는 기존 연결 레코드 병합 규칙을 따라 같은 상태와 시각을 표시한다.

## 화면 표시

- O 버튼 호버: `입력일시 2026-08-03 14:25` 형식으로 한국시간을 표시한다.
- 새 시각이 없는 기존 O 데이터: `입력일 2026-08-03`처럼 기존 날짜만 표시한다.
- X 버튼에는 저장된 입력시각을 표시하지 않는다.

## 오류 및 호환성

- 마이그레이션 전 배포를 대비해 새 시각 컬럼이 없으면 기존 날짜 저장 방식으로 후퇴한다.
- 마이그레이션이 적용되지 않은 상태에서도 O/X 저장 자체는 중단하지 않는다.
- 다른 카드 필드나 기존 서류전달 상태를 초기화하거나 덮어쓰지 않는다.

## 검증

- X에서 O 전환 시 날짜와 시각이 함께 저장되는지 테스트한다.
- 기존 O를 다시 저장해도 최초 시각이 유지되는지 테스트한다.
- O에서 X 전환 시 날짜와 시각이 모두 비워지는지 테스트한다.
- 연결 계정 병합 후 같은 시각이 노출되는지 테스트한다.
- 시각이 없는 기존 O는 날짜만 표시하는지 테스트한다.
- 전체 Node 테스트와 Vercel 함수 수 제한 테스트를 실행한다.
