# 삼현 계정 전용 진행현황 설계

## 목적

삼현 사용자가 현대코퍼레이션H 화물의 진행현황과 서류전달 상태를 확인하되,
화주 요청 기능과 내부 관리용 상세 열은 보지 않도록 전용 화면 범위를 제공한다.

## 계정

- 로그인 아이디: `shyun`
- 초기 비밀번호: 사용자에게 별도 전달하며 저장소에는 기록하지 않는다.
- 계정 분류: `samhyeon`
- 화물 필터: `현대코`
- 비밀번호는 `pgcrypto` bcrypt 해시로 저장한다.
- 관리자 화면에서는 아이디와 비밀번호 재설정 상태만 표시하며 기존 비밀번호를
  복호화하거나 노출하지 않는다.

## 화면 범위

- BL별 진행현황의 기본 정보부터 `양도증`까지 표시한다.
- `서류수령요청`, `수입신고요청`은 숨긴다.
- `양도증` 이후의 검역, 유통이력, 스티커, 문서 파일 열은 숨긴다.
- `서류전달`의 삼현/창고 상태는 표시하되 삼현 계정에서는 읽기 전용이다.
- 관리자는 기존과 같이 모든 열과 상태 변경 기능을 유지한다.
- `반입예정일` 계열의 사용자 표시 문구는 `입고(예정)일`로 통일한다.

## 데이터 보존

- 전용 화면은 열 가시성만 변경하고 저장된 화물·요청·서류·날짜·상태 값은
  변경하지 않는다.
- 마이그레이션은 계정 분류 제약과 삼현 계정만 추가한다.
- 기존 연결 계정의 화물 행은 로컬 동기화의 계정 필터 규칙으로 생성·갱신한다.

## 검증

- 로그인 및 관리자 API가 `samhyeon` 분류를 보존한다.
- 삼현 화면에서 요청 열과 양도증 이후 열이 숨겨진다.
- 서류전달 열은 표시되지만 관리자 전용 토글은 제공되지 않는다.
- 관리자 계정 화면에 비밀번호 해시가 노출되지 않는다.
- 기존 대시보드, 계정, 서류전달 회귀 테스트가 모두 통과한다.
