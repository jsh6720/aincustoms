# 모바일 원본서류 화주요청 우선 표시 설계

## 목표

관리자 모바일 원본서류 수취관리 화면에서 화주가 원본서류 수령을 요청한 B/L을 즉시 식별하고 우선 처리할 수 있게 한다.

## 표시 규칙

- `last_original_doc_request` 또는 `last_original_doc_request_id`가 있으면 화주 요청 건으로 본다.
- 요청 건은 카드 상단에 상태 배지를 표시한다.
- OBL 원본이 수령된 요청 건은 `요청/수령O` 초록색 배지로 표시한다.
- 아직 OBL 원본이 수령되지 않은 요청 건은 `화주 수령요청` 주황색 배지로 표시한다.
- 요청 희망일이 있으면 배지 옆에 `희망 YYYY-MM-DD`를 표시한다.

## 정렬 규칙

1. 미수령 화주 요청 건
2. 수령 완료 화주 요청 건
3. 요청이 없는 일반 B/L

같은 그룹 안에서는 요청 건은 최신 요청 시각순, 일반 건은 B/L 오름차순으로 정렬한다. 검색 결과에도 같은 정렬을 적용한다.

## 구현 범위

- 기존 `/api/cargo-data` 응답만 사용한다.
- 데이터베이스 컬럼 및 API 계약은 변경하지 않는다.
- 홈페이지 원본과 로컬/Vercel 사본을 동일하게 유지한다.
- 모바일 저장, 승인, 메일 기능은 변경하지 않는다.

## 검증

- 요청 우선순위 정렬 함수의 실제 반환 순서를 테스트한다.
- 미수령/수령완료/일반 배지 렌더링을 테스트한다.
- 전체 Node 테스트와 배포 상태를 확인한다.
