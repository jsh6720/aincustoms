# 진행 현황 캘린더 OBL 상태 표시 설계

## 목적

BL 진행 현황 하단 캘린더의 입항 일정에 해당 BL의 OBL 원본 수령 상태를 함께 표시한다.

## 표시 규칙

- `card.obl_received`가 `true`이면 `입항 {BL번호} (OBL O)`로 표시한다.
- `card.obl_received`가 `false`이거나 값이 없으면 `입항 {BL번호} (OBL X)`로 표시한다.
- 입항 일정의 날짜 산정, 색상, 정렬, 필터링 동작은 변경하지 않는다.
- 서류수령 일정 등 다른 캘린더 이벤트 문구는 변경하지 않는다.

## 변경 범위

동일한 진행 현황 화면을 제공하는 로컬 템플릿, 홈페이지 소스, Vercel 배포 사본의
`progressCalendarEvents()` 입항 이벤트 문구를 같은 방식으로 변경한다.

## 검증

- OBL 수취 상태가 `true`인 입항 일정에 `(OBL O)`가 표시되는지 확인한다.
- OBL 수취 상태가 `false`이거나 없는 입항 일정에 `(OBL X)`가 표시되는지 확인한다.
- 홈페이지 전체 Node 테스트와 로컬 정적 회귀 테스트를 실행한다.
