# 기능별 메일 설정, OBL 입력, 진행현황 정렬 구현 계획

**목표:** 기능별 메일 수신처를 관리하고 OBL 접수일 입력, BL원본 열 배치,
BL 진행현황 정렬을 안정적으로 개선한다.

**구조:** 기존 `cargo-admin` API를 확장하고 공통 메일 설정 테이블과 메일 수신처
해결 유틸리티를 추가한다. 날짜와 정렬은 테스트 가능한 유틸리티로 고정하며
홈페이지와 로컬 배포 사본을 동일하게 유지한다.

## 작업 1: 회귀 계약

- [ ] 메일 설정 마이그레이션 계약 테스트
- [ ] 메일 수신처 우선순위/중복 제거 테스트
- [ ] OBL 날짜 입력 정규화 테스트
- [ ] 납품처/입항일/마일스톤/BL 정렬 테스트
- [ ] OBL 접수일과 BL원본 열 순서 테스트

## 작업 2: 데이터와 관리자 API

- [ ] `cargo_mail_settings` 마이그레이션 추가
- [ ] `cargo-admin` GET에 설정 조회 추가
- [ ] `cargo-admin` POST에 관리자 전용 일괄 저장 추가
- [ ] 테이블 미적용 상태의 fallback 처리

## 작업 3: 메일 발송 경로

- [ ] 공통 수신처 해결 유틸리티 추가
- [ ] 출고/수입신고/서류수령 요청에 계정 override와 공통 설정 적용
- [ ] 반입정보 변경 알림에 공통 설정 적용
- [ ] 원본수령/OBL접수 확인에 기능별 To/CC 적용
- [ ] 요청자 및 추가 수신인 병합과 중복 제거

## 작업 4: 화면

- [ ] 관리자 설정에 기능별 To/CC 편집 영역 추가
- [ ] 계정별 필드명을 요청메일 우선 수신처로 정리
