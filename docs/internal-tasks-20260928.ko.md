# 회사 할 일 · 2026-09-28

## 사용 방법

`/note`에서 기존 공유 비밀번호로 입장한 뒤 왼쪽 **회사 할 일** 또는 상단 **회사 할 일 ↗**을 선택합니다.

1. **담당자 등록**에서 이름을 등록합니다. 이는 배분용 이름이며 별도 로그인·권한 계정이 아닙니다.
2. **할 일 추가**에서 제목, 내용, 담당자, 업무일, 반복 주기, 선택적인 종료일을 입력합니다.
3. 담당자·업무일·상태·검색어로 조회하고 체크 상자로 완료 처리합니다.
4. **완료 기록**에서 체크를 해제하면 완료 취소가 가능합니다. **보관**은 전체 반복 업무를 보관하며 삭제하지 않습니다. 보관된 업무에서 복원할 수 있습니다.

## 날짜 기준

- 날짜는 한국 시간 기준 날짜이며 시간·메일·푸시 알림은 포함하지 않습니다.
- 매일: 주말을 포함한 매일. 15일마다: 시작일에서 15일 간격이며 매월 1일/15일이 아닙니다.
- 매월: 시작일과 같은 날짜. 없는 날짜는 말일로 표시하되 다음 달에 원래 날짜로 돌아옵니다. 예: 1월 31일 → 2월 28일 → 3월 31일.
- 종료일은 포함합니다. 날짜 범위는 2000~2100년입니다.
- 날짜 필터가 없으면 각 업무의 **가장 이른 미완료 일정 한 건**을 표시합니다. 특정 업무일을 선택하면 그 날짜의 반복 일정을 조회합니다. 미처리 과거 업무는 자동 완료하지 않습니다.
- 일정·담당자 수정은 해당 업무 전체에 적용됩니다. 완료한 날짜와 완료 표시 이름은 남으며, 제목·담당자 표시는 현재 업무 정보를 사용합니다.

## 저장·보안·동시 수정

기존 노트와 같은 Yjs 문서의 별도 `companyTasks`, `taskPeople`, `taskCompletions` 맵을 사용합니다. 기존 노트 본문을 바꾸거나 새 DB/공개 테이블을 만들지 않습니다. 기존 세션·CSRF·서버 인증·암호화 캐시·비밀번호 변경 절차를 그대로 사용합니다.

반복 일정은 날짜 규칙으로 계산하며, 접속 타이머나 완료 클릭으로 다음 업무를 추가하지 않습니다. 동일 업무/날짜 완료를 두 명이 동시에 처리해도 다음 업무가 중복 생성되거나 건너뛰지 않습니다. 서로 다른 필드의 변경은 병합됩니다. 같은 필드나 같은 날짜의 완료/취소가 충돌하면 Yjs의 결정적 최종값으로 수렴합니다.

공유 비밀번호를 아는 구성원 모두 업무를 편집할 수 있습니다. 담당자는 최대 100명, 업무는 보관 포함 최대 2,000개(클라이언트 한도, 동시 생성 시 일시 초과 가능), 화면은 100건씩 더 보기입니다. 이름 중복은 공백·대소문자 정규화로 방지하지만 서로 오프라인인 사용자가 동시에 같은 이름을 등록하는 경우 별개 항목이 생길 수 있습니다.

전체 JSON 백업은 Yjs 상태와 사람이 읽을 수 있는 `companyTasks`(담당자·업무·완료 기록)를 포함합니다. 이미지 파일은 기존과 같이 별도 저장됩니다. 백업에는 내부 내용이 있으므로 내부 보관해야 합니다.
