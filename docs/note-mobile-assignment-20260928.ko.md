# 노트·할 일 모바일 및 담당자 배정

## 범위

- 기존 /note 주소와 인증·Yjs 공유 데이터를 그대로 사용. DB 스키마·비밀번호·원본 문서 변경 없음.
- 모바일 하단 노트/할 일/목록 이동, 터치 크기 버튼, 노트 읽기·편집, 접이식 담당자/날짜 필터, 좁은 화면·키보드 높이 대응.
- 데스크톱 우측 담당자별 블록으로 업무를 드래그하여 배정. 미배정으로 이동도 가능.
- 드래그 대신 업무의 배정 버튼을 누른 뒤 담당자 블록을 클릭하거나 키보드로 선택 가능.
- 선택 중이 아닐 때 담당자 블록 클릭은 조회 필터만 변경. 숫자는 필터와 무관한 미완료 업무 수.
- 담당자 변경은 반복 업무 전체에 적용. 일정·업무 내용·완료 기록은 덮어쓰지 않음. 신규 등록 담당자도 자동 표시.
- 모바일은 업무 수정 창에서 담당자 선택. 담당자 이름은 인증 계정이 아니며 메일/알림은 발송하지 않음.

## 검증과 복구

- 단위 검사 126/126, 비밀정보·미러 검사 5/5 통과.
- 합성 서버에 연결한 브라우저 검사: 실제 drag/drop, 연속 배정/미배정, 키보드 배정, 외부 drop 무시, PC→모바일 동기화, 반복/완료 기록 보존.
- 모바일 에뮬레이션 320/390/430px: 노트 읽기와 목록 이동, 할 일 조회·필터, 390x420 키보드 크기 모달 취소, 가로 넘침 없음.
- 기존 노트·이미지 브라우저 회귀 검사 포함. 실제 휴대폰 하드웨어 및 운영 비공개 문서에 쓰기 검사는 수행하지 않음.
- 드래그 도중 안내 메시지가 블록 위치를 옮기던 문제를 테스트에서 발견해 피드백을 블록 뒤로 이동. 연속 드래그 검증으로 재발 방지.
